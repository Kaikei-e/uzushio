Sure, here's an example of how you can create a simple website in HTML that displays a random joke when a button is clicked:

```html
<!DOCTYPE html>
<html>
<head>
	<title>Random Joke Generator</title>
	<meta charset="UTF-8">
	<meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
<body>
	<h1>Random Joke Generator</h1>
	<p>Click the button below to get a random joke:</p>
	<button onclick="getRandomJoke()">Get Joke</button>
	<p id="joke"></p>

	<script>
		function getRandomJoke() {
			// List of jokes
			var jokes = [
				"Why did the tomato turn red? Because it saw the salad dressing!",
				"What do you call a fake noodle? An impasta!",
				"Why don't scientists trust atoms? Because they make up everything!",
				"Why did the chicken cross the playground? To get to the other slide!"
			];

			// Get a random joke from the list
			var randomJoke = jokes[Math.floor(Math.random() * jokes.length)];

			// Display the joke on the page
			document.getElementById("joke").innerHTML = randomJoke;
		}
	</script>
</body>
</html>
```

In this example, we have a simple HTML page with a heading, a paragraph, a button, and an empty paragraph with an ID of "joke". When the button is clicked, the `getRandomJoke()` function is called, which selects a random joke from a list of 4 jokes and displays it in the "joke" paragraph using the `innerHTML` property.
