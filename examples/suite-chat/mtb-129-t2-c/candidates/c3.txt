Yes, there exists an algorithm with better time complexity. The algorithm is called selection sort and it has a time complexity of O(n^2). It can be implemented as follows:
```
def selectionSort(nums):
    for i in range(len(nums)):
        min_idx = i
        for j in range(i+1, len(nums)):
            if nums[min_idx] > nums[j]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]

selectionSort(nums)
```
