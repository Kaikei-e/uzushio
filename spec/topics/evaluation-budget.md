# What the standard's own upkeep is allowed to cost

A standard about measuring an agent has work of its own: its tests, its
records, the repositories it dogfoods on. That work is a budget, and a
budget is spent whether or not anybody counts it. This is the subject of
every rule that caps the upkeep so it cannot crowd out the thing being
measured — how much test code a repository may carry against its own,
how much a single change may claim to have done, and which repositories a
held-out measurement is allowed to run on.
