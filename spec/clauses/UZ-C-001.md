# An accepted MUST is enforced by a conformance test

An accepted clause that claims `MUST` or `MUST_NOT` MUST be the target of
an `enforces:` edge from a `conform` document. A strict rule with no test
is a standard saying one thing and checking another; until a test exists
the clause carries the force of a `SHOULD`.
