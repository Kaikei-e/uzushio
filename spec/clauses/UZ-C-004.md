# An agent asks the graph what is in force

An agent asking what uzushio currently requires MUST use `docdag query --binding`
or `docdag context <id>`, not a listing of `spec/`. `resolve` answers what
replaced a superseded clause. `validate --touching` reports only what one
edit can break.
