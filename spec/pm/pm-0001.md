# Unstructured decision records whose status drifted

A directory of Markdown decisions whose supersession never moved the
predecessor's status, whose `supersedes:` pointed at a file nobody wrote,
and whose "what is in force" answer required reading every file. The case
the clauses point at as their counterexample: review did not catch graph
properties, because nothing was checking the graph.
