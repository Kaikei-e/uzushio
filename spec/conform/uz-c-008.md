# Check that no held-out task runs the toolchain

For every task the suite manifest puts in the held-out split, the test
resolves the `repo` path from the task's manifest and fails if it leaves
the task directory, then reads the module path the task presents and fails
if it names uzushio, CMoA or DocDag. A held-out task with no directory, no
task manifest, or no module to read fails as well: the clause is a MUST,
and a check that cannot see its subject has not cleared it. Where there is
no suite manifest at all there is no split to read, and the test says so
and exits 0.
