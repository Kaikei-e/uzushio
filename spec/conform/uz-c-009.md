# Check that a calibration's report is there

Reads the `report:` key of every document under the calibration directory
and fails where the key is missing or the path it names does not resolve
to a file under the vault root. A vault holding no calibration passes and
says how many it checked, so a corpus that stopped writing them is visible
as a zero rather than as a silent success.
