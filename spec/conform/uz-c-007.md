# Check that a pull request claims one roadmap step

Reads the pull request's title and body out of the GitHub Actions event
payload named by `GITHUB_EVENT_PATH` and collects the step markers the
clause defines. More than one distinct number fails; a number outside the
roadmap's 1 to 7 fails and is named; one number in range passes and is
printed; none passes and is printed as unlabelled. Anywhere but a
`pull_request` event there is nothing to read, and the test says so and
exits 0.
